# Motorola_Sales_PowerBI_Dashboard
Motorola Sales Dashboard built using Microsoft Power BI

## Project Overview
An interactive Power BI dashboard created to analyze Motorola mobile sales performance.

## Tools Used
- Microsoft Power BI
- Data Visualization
- DAX
- Data Analysis

## Dashboard Features
- Total Sales Analysis
- Total Quantity Analysis
- Transaction Analysis
- Average Sales
- Sales by City
- Sales by Mobile Model
- Sales by Payment Method
- Customer Ratings
- Monthly and Daily Sales Trends

## Project Files
- Power BI Dashboard (.pbix)
- Dashboard images
- Supporting project visuals
